# GitHub 101 Checklist

Paste this into your own notes, or post it in the community when you're done. Tick each line as
you complete it. Full instructions for any step are in the written guide,
`github-101-written-guide.md`.

```
[ ] I have a GitHub account. If I did not, I made one at github.com first, using an email I check.
[ ] I know which email and password I'm using for GitHub, and I've written it down somewhere I'll
    find again.
[ ] Two-factor authentication is on.
[ ] I've downloaded my recovery codes and saved them somewhere that isn't my phone.
[ ] My organization exists.
[ ] A second owner is added and has accepted.
[ ] My first teammate is added, with the access level I chose on purpose, not the widest one by
    default.
[ ] I know what happens if I ever remove someone: it stops what's next, it doesn't undo what they
    already have.
[ ] My team's shared repository exists, and I checked its visibility on purpose rather than
    assuming it.
[ ] If I ever commit a real secret by accident, I know the fix is a new key, not a deleted file.
[ ] I know the three things that are always a scam now that I own an organization: a sign-in link
    inside an email, anyone asking for my codes, and anything asking for access to my whole
    organization when it only needs one repository.
[ ] This week's build is somewhere on my machine or my team's shared space, and I can find it
    again.
[ ] I posted a screenshot of my organization's People page in the community.
```
