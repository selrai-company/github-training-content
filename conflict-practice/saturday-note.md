# Saturday note

This file is here for the merge conflict practice, and nothing else.

One line below has deliberately not been decided. That single line is the only line meant to change.
Leave every other line exactly as it is, because the practice only works if the rest of the file
matches on both sides.

Saturday: closed all day

Two practice branches each change that one line to something different. One says the cafe opens on
Saturday morning. The other says it is closed. Both cannot be true, so git stops and asks you which
one you meant. That question is the whole lesson.
